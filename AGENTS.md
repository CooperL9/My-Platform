# Greatest Invention Yet - AI Development Rules

This project is a private digital planner + journal app.

Core product experience:
- calm
- minimal
- private
- emotionally supportive
- simple
- reflective

This app should feel like:
- a digital diary
- a reset button
- a private sanctuary

This app should NOT become:
- social media
- productivity overload
- feature bloated
- overly complex

Current stack:
- Next.js
- TypeScript
- Tailwind
- localStorage (temporary MVP storage)
- Vercel
- Supabase later

Completed MVP features:
- login UI
- signup UI
- homepage
- journal page
- journal persistence
- journal history
- one journal entry per day
- mood page
- mood persistence
- mood history
- one mood entry per day

Remaining MVP priorities:
- planner functionality
- navigation cleanup
- final testing
- deployment

Rules:
- Do NOT install unnecessary libraries
- Do NOT rewrite working code unless explicitly asked
- Do NOT add backend architecture yet
- Do NOT overengineer
- Keep UI soft and minimal
- Maintain current folder structure
- Preserve existing functionality
